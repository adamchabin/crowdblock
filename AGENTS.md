# Agent Guidelines

## Language Standards
All code comments, log messages, and documentation within the crowdblock project MUST be written in English. This ensures consistency, maintainability, and accessibility for the international development team and community.

### Rationale:
- English is the lingua franca of software development
- Ensures all team members can understand code regardless of native language
- Facilitates community contributions from worldwide developers
- Aligns with standard practices in open-source projects

### Enforcement:
- Code reviewers should verify that new comments/logs are in English
- Existing non-English comments should be translated during refactoring
- Automated checks may be implemented to enforce this standard
